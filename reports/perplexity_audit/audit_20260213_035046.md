### 🔴 REL-P001: Missing transaction boundaries around multi-node DAG operations

- **Severity:** P0
- **Category:** reliability/transaction_boundaries
- **File:** `memory/substrate_dag.py` (L248-248)
- **Fix Effort:** 8h
- **ADR Violations:** ADR-0028

LangGraph DAG executes intake_node → reasoning_node → memory_write_node → graph_sync_node sequence without transaction boundaries. Partial failures after memory writes leave inconsistent state across Neo4j, semantic embeddings, and checkpoints (ADR-0028 violation).

**Before:**
```python
result = await graph.ainvoke(input, config)
```

**After:**
```python
async with substrate_service.begin_transaction(envelope):
    result = await graph.ainvoke(input, config)
    substrate_service.commit_transaction(result)
```

- **File:** `memory/substrate_dag.py` (L210-230)
- **Fix Effort:** 4h
- **ADR Violations:** ADR-0009

intake_node early returns on validation failure without cleanup or PacketEnvelope rejection logging (ADR-0009). Downstream nodes lack try/except with state rollback.

**Before:**
```python

```

**After:**
```python

```
