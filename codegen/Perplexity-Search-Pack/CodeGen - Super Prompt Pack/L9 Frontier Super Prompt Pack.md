## 🎯 Critical Success Factors

### ✅ Code Quality Checklist (5-Second Scan)

Before considering any code complete:

- [ ] `import structlog` present, ZERO `print()` statements
- [ ] All I/O operations are `async def` + `await`
- [ ] All function signatures have full type hints
- [ ] Significant operations write to memory substrate
- [ ] High-risk tools check Igor approval first
- [ ] Exceptions caught with structured logging
- [ ] Footer metadata block present (version, author, kernel_refs)
- [ ] DORA block present (risk, monitoring, SLO targets)


### 🚫 Anti-Patterns to Avoid

| ❌ WRONG | ✅ CORRECT |
| :-- | :-- |
| `print("message")` | `logger.info("event", key=value)` |
| `def sync_io():` blocking | `async def async_io():` non-blocking |
| `def func(arg):` no types | `def func(arg: str) -> dict:` typed |
| `return {}  # TODO` stub | Complete implementation |
| Execute git_commit directly | Check Igor approval first |
| Skip memory persistence | Write to PacketEnvelope |
