## Usage Scenarios

### Scenario 1: Advisory Analysis
**User**: "Analyze the current memory substrate integration and recommend improvements."

**AI Response** (using super prompt):
1. Identifies specific code locations with gaps
2. Recommends 3-5 improvements with code examples
3. Explains trade-offs for each option
4. Suggests related concerns (e.g., lineage tracking gaps)
5. Prioritizes by impact/effort matrix

### Scenario 2: Feature Implementation
**User**: "Implement metacognitive self-assessment for the CA agent."

**AI Response** (EXECUTION mode):
1. **Phase 0**: Generates deterministic TODO plan
   - Files to modify (with line numbers)
   - Files to create (with size estimates)
   - Expected behaviors and imports
   - **STOPS and WAITS for approval**

2. **User Approves**: "YES, proceed"

3. **Phases 1-6**: Executes implementation
   - Phase 1: Baseline verification
   - Phase 2: Code implementation
   - Phase 3: Guards and tests
   - Phase 4: Validation
   - Phase 5: Recursive verification
   - Phase 6: Evidence report

4. **Outcome**: Production-ready code with 85%+ test coverage

### Scenario 3: Code Review
**User**: "Review this agent implementation for L9 pattern compliance."

**AI Response** (using super prompt):
1. Checks structured logging (structlog vs print)
2. Verifies async/await patterns
3. Validates type hints
4. Confirms memory substrate integration
5. Checks kernel governance respect
6. Suggests specific improvements with code examples

## Risk Assessment & Mitigations

### Risk: AI generates non-compliant code
**Mitigation**: CI enforcement gates (ruff, mypy, pytest, tool wiring check)  
**Fallback**: ADVISORY mode for review before EXECUTION mode

### Risk: Super prompt becomes stale as L9 evolves
**Mitigation**: Version tracking + periodic updates  
**Cadence**: Monthly review, quarterly major updates

### Risk: Phase 0 approval skipped in EXECUTION mode
**Mitigation**: Explicit STOP instruction in super prompt  
**Enforcement**: User must type "YES, proceed" to continue

### Risk: Generated code introduces security vulnerabilities
**Mitigation**: Zero-trust patterns + kernel enforcement baked into templates  
**Validation**: Security review required for high-risk tool additions

### Risk: Incomplete pattern coverage for edge cases
**Mitigation**: ADVISORY mode flags unknown patterns  
**Resolution**: Iterative super prompt enhancement based on usage
